# SkillNudge

SkillNudge connects real Agent Sessions to traceable Skill evolution.

## Why

A useful Skill change should begin with a real session or user feedback, keep
the reason it was made, and remain reviewable before it replaces anything.

## Core Flow

```text
Session
  -> Evidence
  -> Skill Evolution
  -> Candidate Skill
  -> Human Accept / Reject
```

## Principles

- Evolution starts from real usage.
- Every candidate keeps its source evidence.
- Skill content and versions are immutable.
- A candidate never becomes active automatically.
