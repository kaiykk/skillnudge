# Decision 0006: No Intervention Is Valid

## Status

`[FROZEN]`

## Decision

`no_intervention` is a first-class possible advice result.

## Context

Some requests are directly answerable. Forcing a Skill or Tool into every run
creates recommendation addiction and unnecessary context or setup friction.

## Consequences

The absence of a recommendation must be distinguished from source failure,
insufficient evidence, and the need for clarification.

## Revisit When

Revisit only if real user outcomes show that direct answers systematically miss
a useful intervention, not merely because a candidate exists.
