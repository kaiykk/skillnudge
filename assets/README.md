# README Visual Assets

The landing pages reference two visual assets:

```text
assets/hero.png
assets/architecture.png
```

## `hero.png`

Use this as the first-viewport project image. It should communicate a
capability intervention advisor for AI coding agents without implying that
SkillNudge is a marketplace or an autonomous self-evolution system.

Recommended direction:

- wide landscape composition;
- restrained, technical visual language;
- clear relationship between a vague task, a capability gap, and a bounded
  intervention;
- no sensitive project data;
- no text that duplicates the README title or slogan.

## `architecture.png`

Use this for the high-level runtime illustration. It should make the eight
steps legible without reproducing the full contracts:

```text
Intake
-> Capability Framing
-> Intervention Planning
-> Query Planning
-> Candidate Acquisition
-> Evidence Hydration
-> Candidate Judgement
-> Final Advice
```

Trace should be shown as crossing the runtime. The image should not suggest
that Review, Grow, Watch, capability evolution, embeddings, or automatic
installation are already implemented.

## Asset conventions

- Keep the filenames stable, or update both `README.md` and
  `README.zh-CN.md` together.
- Prefer compressed PNG files suitable for a GitHub README.
- Do not include API keys, private repository content, user data, or
  credentials in visual assets.
- The current repository may leave these files absent while the README
  placeholders are being designed.
